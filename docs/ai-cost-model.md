# Экономика AI: сколько реально стоит тренировка

Документ отвечает на два вопроса: сколько стоит запуск и где деньги утекали.
Цены проверены 2026-08 и живут в коде в одном месте: `apps/api/src/lib/pricing.ts`.

---

## Что стоит одна сессия

Сессия v2 = кейс-карта (обычно из кеша) + речь + **один** вызов судьи.
Модель одна, Claude Haiku 4.5 через OpenRouter ($1 / $5 за MTok).

| Статья | Раунд v1 | Сессия v2 | Что изменилось |
|---|---|---|---|
| LLM, оппонент | ~$0.006 (3 хода) | ~$0.0006 | три полноценные реплики заменены одним POI, и он опционален |
| LLM, судья | ~$0.007 | ~$0.006 | одна речь вместо транскрипта из шести реплик |
| LLM, кейс-карта | нет | ~$0.002, **делится на всех** | генерируется один раз на тему и кешируется |
| STT, 3 минуты речи | $0.0020 | $0.0020 | `whisper-large-v3-turbo` |
| TTS | $0.019 | **0** | озвучку не просил ни один респондент, дефолт `stub` |
| **Итого, текст + голосовой ввод** | **~$0.015** | **~$0.007** | |

Главный сдвиг: раньше 40% стоимости уходило на AI-оппонента, то есть на
функцию, нехватку которой в опросе назвали 6% дебатёров. Теперь деньги идут
туда, ради чего возвращаются: разбор и материал.

### Почему кейс-карта почти бесплатна

Материал по теме одинаков для всех. Первый ученик на теме оплачивает ~$0.002,
остальные получают карту из `case_cards`. На 15 темах это разовые $0.03 на всю
платформу, а не расход на каждого.

## Пилот

Из расчёта 8 сессий на ученика.

| | текст + голосовой ввод | с озвучкой (не рекомендуется) |
|---|---|---|
| 50 учеников (400 сессий) | ~$3 | ~$11 |
| 100 учеников (800 сессий) | ~$6 | ~$21 |

Закладывай ×2 на ретраи, смоки и ночные eval-прогоны. Депозита $20 на
OpenRouter хватает на текстовый пилот с сотней учеников с большим запасом.

Блиц отдельно дёшев: один короткий вызов, ~$0.002 за сессию. Именно он должен
брать на себя частоту, а не полная речь.

## Где деньги утекали

### 1. STT и TTS не считались вообще

Суточный бюджет читался из `DebateRound.costEstimateUsd`, куда попадали только
вызовы LLM. У `/voice/stt` и `/voice/tts` был единственный барьер: rate limit.
При `TTS_PROVIDER=openai` это **~$14 в час с одного аккаунта**, просто дёрганьем
эндпоинта в цикле.

Починено: таблица `usage_events`. Каждый платный вызов пишет строку с
провайдером, моделью, единицами и стоимостью. Суточный лимит считается по ней.

### 2. Учёт был мёртвым кодом

Миграция `usage_events` лежала в репозитории с 1 августа, но модели в
`schema.prisma` не было. То есть `prisma.usageEvent` не существовал, и весь
spend-контроль не вызывался ниоткуда. Это чинится только вместе:
миграция + модель + вызовы в сервисе.

### 3. Лимит проверялся после траты, а не до

Старый страж смотрел на уже потраченное, поэтому последний вызов всегда уходил
за потолок. Теперь проверяется `потрачено + проектная стоимость вызова`.

### 4. `DAILY_COST_LIMIT_USD = 1.0` не срабатывал никогда

При цене сессии $0.007 двадцать сессий стоят $0.14, поэтому раньше упирался
лимит по количеству, а денежный кап был украшением. Опущен до **$0.25**.

### 5. Суммаризатор

Тратил отдельный вызов LLM, чтобы сжать историю раунда. В v2 истории нет:
судья видит одну речь целиком. Агент остался только в legacy-пути.

## Ручки

| Переменная | Дефолт | Смысл |
|---|---|---|
| `DAILY_COST_LIMIT_USD` | `0.25` | суточный потолок в деньгах на ученика |
| `DAILY_SESSION_LIMIT` | `20` | суточный потолок в сессиях |
| `DAILY_TTS_CHARS_LIMIT` | `4000` | суточный потолок символов озвучки |
| `DAILY_STT_SECONDS_LIMIT` | `900` | суточный потолок секунд распознавания |
| `POI_ENABLED` | `true` | `false` = в сессии остаётся ровно один платный вызов |
| `TTS_MAX_CHARS` | `420` | потолок одной озвучки |
| `GROQ_STT_MODEL` | `whisper-large-v3-turbo` | модель распознавания |
| `SPEECH_MAX_CHARS` | `4000` | потолок длины речи, он же потолок промпта судьи |

## Что смотреть после запуска

```sql
-- Куда реально уходят деньги за сутки
SELECT kind, provider, model, count(*), round(sum(cost_usd), 4) AS usd
FROM usage_events
WHERE created_at >= date_trunc('day', now())
GROUP BY 1, 2, 3
ORDER BY usd DESC;

-- Топ прожигателей бюджета
SELECT user_id, round(sum(cost_usd), 4) AS usd
FROM usage_events
WHERE created_at >= now() - interval '7 days'
GROUP BY 1 ORDER BY usd DESC LIMIT 20;

-- Кейс-карты: сколько тем уже оплачено разово
SELECT count(*) AS cached_topics FROM case_cards;
```

Если в первой выборке `LLM_CASE` растёт линейно с числом сессий, кеш не
работает и мы платим за один и тот же материал повторно. Если выше `LLM_JUDGE`
стоит `TTS`, продукт платит за красоту вместо обучения.
