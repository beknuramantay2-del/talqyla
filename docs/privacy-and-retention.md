# Данные учеников: что мы храним, зачем и как долго

Этот документ существует по одной причине: **все наши пользователи — несовершеннолетние**
(7–11 класс), и мы записываем их голос и отправляем его сторонним AI-сервисам.
Первый вопрос от любой школы, с которой пойдёт разговор о внедрении, будет именно этот.

## Что мы храним

| Данные | Где | Зачем |
|---|---|---|
| Email, имя ученика | `users` | Вход в аккаунт |
| Email родителя + отметка о согласии + версия текста согласия | `users` | Правовое основание обработки |
| Класс, уровень, цель | `student_profiles`, `onboarding_quizzes` | Калибровка сложности оппонента |
| Текст реплик ученика (расшифровка речи) | `debate_turns.content_text` | Работа оппонента и судьи в рамках раунда |
| Оценки по 5 навыкам, суммарный балл | `skill_scores`, `round_feedback.total_score` | История прогресса |
| Разбор судьи с цитатами ученика | `round_feedback` | Обратная связь после раунда |
| Токены и стоимость каждого вызова | `debate_turns`, `debate_rounds` | Контроль расходов и дневные лимиты |

Аудиофайлы в текущем MVP **не сохраняются**: запись уходит в распознавание речи и
дальше живёт только как текст.

## Кому данные уходят

| Обработчик | Что получает |
|---|---|
| OpenRouter (модели Anthropic) | Текст аргумента и реплик — для оппонента и судьи |
| Groq | Аудио речи ученика — для распознавания |
| OpenAI | Текст реплики оппонента — для синтеза голоса |

В dev-режиме все три работают в режиме `stub` и наружу не ходит ничего.

## Согласие родителя

При регистрации обязательны `parentEmail` и `parentalConsent: true`
(поведение управляется `PARENTAL_CONSENT_REQUIRED`). Мы сохраняем момент согласия
и **версию текста** (`CONSENT_VERSION`), чтобы при изменении политики было понятно,
кто на что соглашался.

## Сколько храним

`TRANSCRIPT_RETENTION_DAYS` (по умолчанию 180 дней). После этого срока задача
очистки обезличивает свободный текст:

- реплики раунда → `[удалено по политике хранения данных]`
- аргумент ученика и цитаты → затираются
- разбор судьи (strengths / weaknesses / advice) → затирается
- **числовые оценки остаются** — иначе исчезнет история прогресса, ради которой
  ученик и занимается

Запуск очистки:

```bash
# один инстанс — встроенный суточный таймер
RETENTION_JOB_ENABLED=true

# несколько инстансов — по крону, ровно один раз в сутки
pnpm retention:purge
```

## Права ученика и родителя

| Действие | Эндпоинт |
|---|---|
| Посмотреть, что о нас хранится | `GET /api/v1/me` |
| Выгрузить всё в JSON | `GET /api/v1/me/export` |
| Удалить аккаунт и все данные безвозвратно | `DELETE /api/v1/me` (пароль + `confirm: "УДАЛИТЬ"`) |

Удаление каскадное: профиль, входной тест, раунды, реплики, оценки, разборы и
сессии уходят вместе с пользователем.

## Чего ещё нет (честный список)

- Нет DPA с обработчиками — при выходе за пределы пилота нужны договоры.
- Нет возрастного гейта на входе: мы верим галочке о согласии.
- Нет отдельного кабинета родителя, только email в профиле ученика.
- Логи ошибок уходят в Sentry; PII из тела запросов вырезается, но сам факт
  сессии там остаётся.
