## Позиционирование

**Было:** AI-спарринг-партнёр для школьных дебатов, раунд из трёх обменов.

**Стало:** тренажёр между турнирами. Одна речь, разбор уровня тренера, один
конкретный дрилл, видимый рейтинг.

Три сдвига:

1. **От раунда к речи.** Атомарная единица — речь на 3–4 минуты, а не
   пятнадцатиминутный раунд. Влезает в ритм «несколько раз в месяц».
2. **От оппонента к аналитику и материалу.** Судья и кейс-карта — ядро.
   Оппонент понижен до опционального POI.
3. **От одиночного трека к рейтингу.** Половина респондентов хочет
   соревноваться.

Аудитория расширяется с «7–11 класс» до школьных и студенческих клубов:
респонденты — активные дебатёры, а не новички.

---

## Как проходит сессия

**Режим «Речь», 8–12 минут.**

1. **Тема и роль, 30 сек.** Резолюция плюс роль (PM / LO / MG / MO). Роль
   определяет, что судья считает выполненной задачей.
2. **Кейс-карта, 2–3 мин.** Стейкхолдеры, 2–3 clash с позициями обеих сторон,
   типовые линии, ловушки. Не готовая речь: ученик собирает свою.
3. **Речь, 3–4 мин, голосом.** Таймер, микрофон, текстовый fallback. По
   желанию один POI в середине — тренировка скорости мышления.
4. **Ballot, мгновенно.** Оценки по пяти навыкам, цитаты из речи, **ровно один
   дрилл** на слабое место.

**Режим «Блиц», 60–90 сек.** Один короткий ответ. Дешёвый, помещается в
перемену, главный драйвер частоты.

**Режим «Разбор», 3–5 мин.** Только кейс-карта, без речи. Закрывает запрос на
материал у половины опрошенных.

## Рейтинг

Очки за **прирост слабого навыка**, а не за объём: база 5, плюс тройная
разница с личным средним по фокусному навыку, потолок 15. Иначе лигу выигрывает
тот, у кого больше свободного времени.

## Экономика

| | v1 (раунд) | v2 (сессия) |
|---|---|---|
| Вызовы модели | 3 хода оппонента + судья | судья (+ POI по желанию) |
| Кейс-карта | нет | 1 раз на тему, дальше из кеша |
| Себестоимость | ~$0.015 | **~$0.007** |
| 100 учеников × 8 сессий | ~$12 | **~$6** |

Голос: STT дешёвый (~$0.002 за 3 минуты на Groq turbo), TTS дорогой и по опросу
не нужен, поэтому по умолчанию `stub`.

## Что осталось сделать до пилота

1. Прогнать `pnpm db:generate && pnpm typecheck && pnpm build` на живом
   окружении: миграция меняет enum, генерация клиента обязательна.
2. Юридический текст родительского согласия.
3. Golden set судьи, подписанный живым тренером.
4. Перенести историю v1 или удалить раунды вместе с их экранами.
