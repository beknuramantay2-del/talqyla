# Рефакторинг v2: что изменено и что проверено

## Что переехало

| Слой | Было (v1) | Стало (v2) |
|---|---|---|
| Единица продукта | раунд из 3 обменов с AI-оппонентом | одна речь + ballot + дрилл |
| Ядро AI | debater (3 вызова) + judge | judge (1 вызов), POI опционален |
| Материал | 15 тем без разбора | кейс-карта, кешируется на тему |
| Рубрика | Structure, Content, Refutation, Logic, Delivery | Structure, Case analysis, Refutation, Quick thinking, Content |
| Выход судьи | список советов | ровно один дрилл на 60 сек |
| Прогресс | средние по раундам | рейтинг за прирост слабого навыка + лига |
| Учёт трат | только LLM внутри раунда | `usage_events`: LLM + STT + TTS |

## Починенные баги

1. **`usage_events` не существовал в Prisma.** Миграция была, модели не было,
   поэтому весь spend-контроль был мёртвым кодом и падал бы в рантайме.
2. **STT и TTS не попадали в бюджет.** Единственным барьером был rate limit.
   При `TTS_PROVIDER=openai` это ~$14 в час с одного аккаунта.
3. **Лимит проверялся после траты.** Последний вызов всегда уходил за потолок.
4. **`DAILY_COST_LIMIT_USD=1.0` не срабатывал никогда** при цене сессии в центы.
   Опущен до `0.25`.
5. **Дашборд грузил все завершённые раунды в память** и считал средние в JS.
   Теперь агрегация в SQL.
6. **`FOCUS_BRIEF` в legacy-оппоненте был полным `Record<SkillKey>`.** Рубрика
   выросла до 7 значений, это ломало typecheck всего API. Стал `Partial`.
7. **Цены дублировались** в провайдере и в комментариях env. Теперь только
   `lib/pricing.ts`.
8. **Polling каждые 3 секунды** в арене больше не нужен: оппонент не отвечает
   в фоне. Убран вместе с ним.

## Проверено локально

Прогон чистой логики (арифметика ballot, рейтинг, капы, экономика): **24 из 24
успешно**.

- рубрика: 5 навыков, `DELIVERY` выведена, максимум 50;
- ballot: сумма, клампинг 0–10, слабейший навык, устойчивость к `null`;
- рейтинг: база 5, прирост +2 даёт 11, провал не уводит в минус, потолок 15;
- капы: `0.246 + 0.008` блокируется ДО вызова, STT по секундам, TTS по символам;
- экономика: сессия $0.0088 против раунда $0.0179, экономия 51%.

Написаны тесты: `session.service.test.ts` (14 кейсов) и `spend.test.ts`
(7 кейсов), включая регрессии на двойную сдачу речи, откат статуса при падении
судьи и некеширование мусорного ответа модели.

## Что НЕ проверено и требует запуска у тебя

Это нельзя выполнить без живого окружения:

```bash
pnpm db:generate   # ОБЯЗАТЕЛЬНО: миграция расширяет enum SkillKey
pnpm typecheck
pnpm test
pnpm build
```

Миграция `20260804090000_practice_sessions_v2` добавляет значения в существующий
enum. Postgres не позволяет использовать новое значение enum в той же
транзакции, где оно создано, поэтому применять её нужно отдельным шагом до
запуска приложения.
