# Staging и запуск MVP: одна инструкция

Этот документ заменяет собой разбросанные по PR чеклисты. Порядок шагов имеет
значение: каждый следующий проверяет предыдущий.

---

## 0. Что должно быть под рукой

- Сервер с Docker и `docker compose` (2 ГБ RAM минимум).
- Домен с HTTPS для API и для веба. **Не опционально:** refresh-cookie ставится
  с `secure: true`, поэтому по `http://` сессия просто не сохранится, а
  приложение вообще не стартует с `http://` в `API_BASE_URL` в production.
- Ключ OpenRouter с положительным балансом.

---

## 1. Секреты

Создай `.env.production` рядом с `docker-compose.prod.yml`. Файл в `.gitignore`,
в репозиторий он не попадёт.

```bash
# Генерируй так — вывод URL-безопасный, ничего экранировать не нужно:
openssl rand -hex 32
```

| Переменная | Что это | Если не задать |
|---|---|---|
| `POSTGRES_PASSWORD` | пароль базы | стек не поднимется |
| `REDIS_PASSWORD` | пароль Redis | стек не поднимется |
| `JWT_ACCESS_SECRET` | подпись токенов, 32+ байта | стек не поднимется |
| `API_BASE_URL` | `https://api.твойдомен` | стек не поднимется |
| `CORS_ORIGIN` | `https://твойдомен` | стек не поднимется |
| `NEXT_PUBLIC_API_URL` | `https://api.твойдомен/api/v1` | стек не поднимется |
| `OPENROUTER_API_KEY` | ключ LLM | раунды падают на первом ходе |
| `STT_PROVIDER` / `GROQ_API_KEY` | голос → текст | голосовой ввод останется заглушкой |
| `TTS_PROVIDER` | текст → голос | оппонент останется без озвучки |
| `SENTRY_DSN` | мониторинг ошибок | падения в проде никто не увидит |

Отдельно в GitHub → Settings → Secrets and variables → Actions добавь
`OPENROUTER_API_KEY`. Без него ночной `judge-eval` молча пропускается, и дрейф
судьи никто не отследит.

---

## 2. Поднять staging

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --build
```

Что произойдёт по порядку: Postgres → Redis → **migrate** (одноразовый
контейнер, применяет миграции и завершается) → API → веб. API не стартует, пока
миграции не отработают успешно, поэтому «база пустая, а сервис уже отвечает»
больше не случится.

Проверка, что всё живо:

```bash
docker compose -f docker-compose.prod.yml ps
curl -s https://api.твойдомен/api/v1/health/ready
```

Ожидаемый ответ: `{"status":"ok","checks":{"db":"ok","redis":"ok"}}`.
Любое `fail` внутри `checks` означает, что до смока идти рано.

Каталог тем на новой базе пустой, без него нельзя создать раунд:

```bash
docker compose -f docker-compose.prod.yml run --rm migrate npx tsx prisma/seed.ts
```

---

## 3. Прогнать смок

```bash
SMOKE_BASE_URL=https://api.твойдомен/api/v1 pnpm smoke
```

Скрипт проходит: liveness → readiness → регистрация с родительским согласием →
refresh (эмуляция перезагрузки страницы) → каталог тем → создание раунда →
сборка аргумента → закрытие раунда → logout → проверка, что отозванная сессия
не оживает. Любой упавший шаг печатает код ответа и тело.

Платная часть (ход оппонента и судья) включается отдельно:

```bash
SMOKE_BASE_URL=https://api.твойдомен/api/v1 pnpm smoke:llm
```

Запускай её после деплоя один раз. Она реально тратит деньги.

**Осторожно с повторами:** регистрация ограничена 3 попытками за 5 минут с
одного IP. Три прогона смока подряд упрутся в 429 — это не поломка, это
работающий rate-limit.

## 4. Что ещё блокирует запуск MVP

Это не про инфраструктуру, но выпускать продукт без этого нельзя.

1. **Golden set судьи помечен как `draft`.** Оценки в нём проставлены
   разработчиком, а не тренером. В таком виде набор ловит дрейф между версиями
   промпта, но **не доказывает правоту оценок**. Пока живой тренер не подписал
   кейсы, нельзя обещать школе объективное судейство.
2. **Нет юридического текста родительского согласия.** Поля, версионирование и
   дата в базе есть, формулировки нет. Пользователи несовершеннолетние, это
   первое, о чём спросит школа.
3. **Голос работает как заглушка**, пока `STT_PROVIDER` и `TTS_PROVIDER` стоят в
   `stub`. Продукт нельзя продавать как голосовой, пока не подключены провайдеры.
4. **Продукт turn-based, не realtime.** Позиционировать как structured sparring,
   не как «перебей оппонента живьём». Realtime переписывает всю экономику: раунд
   стоит не центы, а доллары.
5. **Дыры уровня high в Next 14.** Закрываются только апгрейдом до Next 16, а это
   ломающее изменение (React 19). Отдельная задача до публичного запуска, не
   после.
6. **Бэкапов нет.** До первого реального ученика нужен `pg_dump` по расписанию и
   хотя бы одна проверенная попытка восстановления.

---

## 5. Откат

```bash
# Только приложение, база не трогается:
docker compose -f docker-compose.prod.yml up -d --no-deps --build api web

# Полная остановка (данные в volume остаются):
docker compose -f docker-compose.prod.yml down
```

Миграции Prisma вслепую откатывать нельзя. Если проблема в схеме —
восстанавливай базу из дампа, а не «отменяй» миграцию руками.
